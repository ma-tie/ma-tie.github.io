## 题目内容

[295. 数据流的中位数](https://leetcode-cn.com/problems/find-median-from-data-stream/)

## 思路分析

[参考资料](https://leetcode-cn.com/problems/find-median-from-data-stream/solution/shu-ju-liu-de-zhong-wei-shu-by-leetcode/)

#### 方法一：两个堆

此方法十分巧妙，这里直接上个来自[这里](https://leetcode-cn.com/problems/find-median-from-data-stream/solution/feng-xian-dui-chong-dui-ding-dui-qiu-zho-a36j/)的图：

<img src="/assets/img/blog/mtank/1612362061-eqjoaI-image.png" alt="1612362061-eqjoaI-image" style="zoom:50%;" />

其实就是利用中位数是最中间的数字的特点，将数字按大小分为个数相等的两部分（或数字较小的部分元素个数可以比数字较大的部分多1）：

1. bigger_nums：较大的一部分数字，它是一个堆顶为最小值的堆；
2. smaller_nums：较小的一部分数字，它是一个堆顶为最大值的堆。

经过这样巧妙地设计后，当元素总数为奇数时，中位数为smaller_nums的堆顶；元素总数为偶数时，中位数为bigger_nums的堆顶与smaller_nums的堆顶的平均值。

具体的做法为：

1. 将新到的数字插入smaller_nums
2. 将smaller_nums的堆顶元素移除，插入bigger_nums
3. 若bigger_nums中的元素数比smaller_nums中的元素多，则进行调整，将bigger_nums的堆顶元素移除，插入smaller_nums
4. 按照“当元素总数为奇数时，中位数为smaller_nums的堆顶；元素总数为偶数时，中位数为bigger_nums的堆顶与smaller_nums的堆顶的平均值”的策略返回中位数。

#### 方法二：插入排序

由于需要将元素插入一个已排序的列表中，同时保证插入后的列表仍有序，因此想到了插入排序。

总的思路就是新来一个数字后就进行插入排序，最后根据数组的下标返回中位数。

在插入排序时，将插入的过程按照二分查找进行了优化，也叫二分插入排序。

#### 方法三：multiset

multiset底层由二叉搜索树实现，且是有序的，插入操作的时间复杂度为O(logn)。

该方法与插入排序类似，也是利用O(logn)的时间复杂度来进行插入并排序，然后找出中位数。只不过multiset不支持用下标进行访问，因此需要使用指针来实时追踪中位数的位置。又因为中位数可能是由两个值计算而来的，因此需要两个指针。

在写代码时，需要按照以下情况考虑：

- 插入前的元素个数是0/奇数/偶数
- 插入的元素与两个指针当前所指的数字的大小关系

其实在本子上简单的写写画画就能清楚了。

另外使用C++的multiset<int>::iterator时需要注意以下两点：

- 插入操作不会影响iterator本来指向的值
- 当multiset中已经有值a的情况下再插入值a，新a会插在旧a后面

关于这两个性质的测试可以见代码中main函数的测试部分。

class MedianFinder3 {
public:
    priority_queue<int> smaller_nums;
    priority_queue<int, vector<int>, greater<int>> bigger_nums; // 注意这里的写法
    /** initialize your data structure here. */
    MedianFinder3() {

    }
    
    void addNum(int num) {
      // 先插入小堆
      smaller_nums.push(num);
      // 进行平衡
      bigger_nums.push(smaller_nums.top());
      smaller_nums.pop();

      // 大堆不能比小堆多
      if (bigger_nums.size() == smaller_nums.size() + 1) {
         smaller_nums.push(bigger_nums.top());
         bigger_nums.pop();
      }
    }

      if (smaller_nums.size() > bigger_nums.size()) {
         return smaller_nums.top();
      } else {
         return float(smaller_nums.top() + bigger_nums.top()) / 2;
      }
    }
};

// 时间复杂度O(logn)，插入操作需要耗费O(logn)
// 空间复杂度O(n)，额外空间O(n)
class MedianFinder {
public:
    multiset<int> nums;
    multiset<int>::iterator left, right;

    /** initialize your data structure here. */
    MedianFinder() {

    }
    
    void addNum(int num) {
      int n = nums.size();
      nums.insert(num);
      

      if (n == 0) {
         left = nums.begin();
         right = nums.begin();
      } else if ((n % 2) == 1) { // 原本是奇数个数字
         // 如1  2  3
         //     ↑↑
         if (num >= *left) {
            ++right;
         } else {
            --left;
         }
      } else { // 原本是偶数个数字
         // 如1 3 5 7
         //     ↑ ↑
         if (num >= *left && num < *right) {
            ++left;
            --right;
         } else if (num < *left) {
            --right;
         } else {
            ++left;
         }
      }
    }
    
    double findMedian() {
       return float(*left + *right) / 2;
    }
};
